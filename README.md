# Shyamli & Amey — Wedding Website

Wedding website for Shyamli and Amey's celebration on 4–5 December 2026 at Tathastu Resort, Pench.

## Preview locally

Open `index.html` directly in a browser, or serve the directory with any static web server.

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive styling and animations
- `script.js` — navigation, countdown, FAQ, and RSVP placeholder behavior
- `logo.png` and `save_the_date.jpg` — wedding artwork

The RSVP form is currently a front-end placeholder and does not store submissions.
